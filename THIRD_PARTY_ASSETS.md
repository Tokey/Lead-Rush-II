# Third-party assets (not in this public repository)

Lead Rush II uses paid or licensed Unity Asset Store content that cannot be redistributed publicly, so it is
excluded by `.gitignore`. To open the project, import these packages into the listed folders (same names and
paths, so existing GUID references resolve), then run **LR2 > Build Everything** in Unity 6000.5.0f1 (HDRP 17.5).

| Folder | Content |
|---|---|
| `Assets/Kinemation/` | KINEMATION FPS Animation Framework (v4). Includes local LR2 fixes in `KRigComponent`, `FPSBoneController` and `FPSCameraController`. |
| `Assets/KinemationDemo/` | Demo content of the FPS Animation Framework (humanoid player, weapons, animations, SWAT soldier) |
| `Assets/Demo/` | Legacy Kinemation v3 FPS Framework demo (old research scene) |
| `Assets/LeartesStudios/` | Leartes Studios environment packs (Abandoned Factory and others) |
| `Assets/ScansFactory/` | ScansFactory photoscanned forest (curated subset) |
| `Assets/UnityTechnologies/` | Unity HDRI Pack and other Unity Technologies Asset Store packs |
| `Assets/AllSkyFree/` | AllSky Free skyboxes |
| `Assets/Polyart/`, `Assets/Orbs/`, `Assets/Rhinox Studio/` | Asset Store environment and VFX packs |
| `Assets/Heat - Complete Modern UI/` | Heat - Complete Modern UI |
| `Assets/LR2/Audio/`, `Assets/Audio/` | Sound effects from a private local library (not licensed for redistribution) |

### Open Font Software (SIL Open Font License 1.1 — Included in Repo)

| Folder / Files | Content | License |
|---|---|---|
| `Assets/LR2/UI/Fonts/SairaStencilOne-Regular.ttf` | **Saira Stencil One** (Omnibus-Type, `SairaStencilOne-OFL.txt`): war-torn stencil display headings (`B32`) | SIL OFL 1.1 |
| `Assets/LR2/UI/Fonts/BarlowCondensed-*.ttf` | **Barlow Condensed** (`BarlowCondensed-OFL.txt`): compact HUD & settings typography (`B32`) | SIL OFL 1.1 |

Also excluded: textures and animations that the LR2 builders derive from those packs (uniform dyes, the skull mask,
packed HDRP masks, the baked reload clip). They are regenerated by **LR2 > Build Everything**.
